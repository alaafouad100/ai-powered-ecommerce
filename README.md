
# AI-Powered E-Commerce System

مشروع متجر إلكتروني ذكي متكامل باستخدام Python, Django, PostgreSQL, و Vanilla JavaScript.

## مميزات المشروع
- تسجيل مستخدم جديد وتسجيل الدخول والخروج.
- تصفح المنتجات والفلترة حسب الأقسام والبحث.
- سلة المشتريات وإضافة وحذف المنتجات وتحديث الكميات.
- تسجيل الطلبات وحفظ سجل الطلبات السابقة.
- محرك توصيات ذكي يقترح منتجات مشابهة مع توضيح سبب الاختيار.
